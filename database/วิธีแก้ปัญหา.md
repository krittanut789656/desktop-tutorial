# วิธีแก้ปัญหา "Unknown column 'Ticker_Symbol'"

## ปัญหา
เจอ Error: `Error Code: 1054. Unknown column 'Ticker_Symbol' in 'field list'`

## สาเหตุ
คุณพยายามใส่ข้อมูลเข้าตาราง แต่ตารางยังไม่ได้ถูกสร้าง

## วิธีแก้ (เลือก 1 วิธี)

---

## ⚡ วิธีที่ 1: ใช้ไฟล์เดียว (แนะนำ - ง่ายที่สุด!)

รันไฟล์นี้ครั้งเดียว มันจะทำทุกอย่างให้:

```bash
mysql -u root -p < database/setup_complete.sql
```

หรือถ้าใช้ MySQL Workbench:
1. เปิด MySQL Workbench
2. ไป File → Run SQL Script
3. เลือกไฟล์ `database/setup_complete.sql`
4. กด Run
5. เสร็จ!

---

## 🔧 วิธีที่ 2: รันทีละไฟล์ (ต้องรันตามลำดับ!)

**สำคัญ: ต้องรันตามลำดับนี้เท่านั้น!**

```bash
# ลำดับที่ 1: สร้าง schema ก่อน
mysql -u root -p < database/schema/01_create_schema.sql

# ลำดับที่ 2: ใส่ข้อมูล ETF ทีหลัง
mysql -u root -p < database/data/02_load_etf_master.sql
```

---

## 🖥️ วิธีที่ 3: ใช้ Command Line MySQL

```bash
# เชื่อมต่อ MySQL
mysql -u root -p

# พิมพ์คำสั่งนี้
```

```sql
-- ลบ database เก่า (ถ้ามี)
DROP DATABASE IF EXISTS etf_backtester_db;

-- สร้าง database ใหม่
CREATE DATABASE etf_backtester_db;

-- เลือกใช้ database
USE etf_backtester_db;

-- รัน script แบบรวม
SOURCE database/setup_complete.sql;
```

หรือ (ถ้าอยู่ในโฟลเดอร์ database):

```sql
USE etf_backtester_db;
SOURCE setup_complete.sql;
```

## ✅ ตรวจสอบว่าสำเร็จหรือไม่

รันคำสั่งนี้:

```bash
mysql -u root -p etf_backtester_db -e "SELECT COUNT(*) as Total_ETFs FROM ETF_Master;"
```

**ผลลัพธ์ที่ถูกต้อง:**
```
+-----------+
|Total_ETFs |
+-----------+
|        50 |
+-----------+
```

ถ้าเห็น `50` แสดงว่าสำเร็จแล้ว! ✅

**วิธีที่ง่ายที่สุด (รันครั้งเดียว):**

```
2. database/data/02_load_etf_master.sql    ← รันทีหลัง
```

## ⚠️ ข้อผิดพลาดที่พบบ่อย

### ❌ ผิด: รันไฟล์ข้อมูลก่อน
```bash
mysql -u root -p < database/data/02_load_etf_master.sql  # ผิด!
```
→ จะเจอ Error: Unknown column

### ✅ ถูก: รันไฟล์ schema ก่อน
```bash
mysql -u root -p < database/schema/01_create_schema.sql  # ถูก!
mysql -u root -p < database/data/02_load_etf_master.sql   # แล้วค่อยรันนี้
```

### หรือใช้วิธีง่ายกว่า: รันแค่ไฟล์เดียว
```bash
mysql -u root -p < database/setup_complete.sql  # ง่ายที่สุด!
```

## 🔍 ตรวจสอบเพิ่มเติม

ตรวจสอบว่า database และ table ถูกสร้างหรือไม่:

```sql
-- ตรวจสอบ database
SHOW DATABASES LIKE 'etf_backtester_db';

-- เลือกใช้ database
USE etf_backtester_db;

-- ดู tables
SHOW TABLES;
-- ควรเห็น: ETF_Master, Price_Data, Strategy_Log

-- ดูโครงสร้างตาราง
DESCRIBE ETF_Master;
-- ควรเห็น: Ticker_Symbol, ETF_Name, Asset_Type, etc.

-- นับจำนวน ETF
SELECT COUNT(*) FROM ETF_Master;
-- ควรได้ 50
```

## 📞 ยังแก้ไม่ได้?

1. ตรวจสอบว่าเชื่อมต่อ MySQL ได้หรือไม่
2. ตรวจสอบ username และ password
3. ตรวจสอบว่ามีสิทธิ์สร้าง database หรือไม่

ลองรันคำสั่งนี้:

```bash
mysql -u root -p -e "SHOW GRANTS;"
```

ต้องมีสิทธิ์ CREATE, INSERT, SELECT อย่างน้อย
